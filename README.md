# Maxim Boost Pro (Companion App)

Aplikasi Android pendamping produktivitas driver:
- Turbo tools: shortcut pengaturan koneksi Android
- Panduan jam potensial (perkiraan umum, bukan data order resmi)
- Shortcut pengaturan jaringan
- Pencarian area potensial di Maps
- Focus mode (screen stays on while app is open)
- Catatan aktivitas order lokal

## Build APK via GitHub Actions
1. Extract ZIP ini.
2. Upload seluruh isi folder ke repository GitHub (pastikan folder `.github/workflows` ikut ter-upload).
3. Buka tab Actions.
4. Pilih `Build Maxim Boost Pro APK`.
5. Tekan `Run workflow`.
6. Setelah selesai, buka run yang berhasil dan download Artifact `Maxim-Boost-Pro-APK`.

APK ini tidak mengakses server Maxim, tidak menjamin order, tidak auto-accept, tidak spoof GPS, dan tidak meningkatkan daya sinyal perangkat.
